# الأرشيف: V1 وV2

كل ما هنا قديم، ونحتفظ به للرجوع إليه فقط. لا نعدّل فيه. النسخة الأصلية الآن هي V3.

| المجلد | ما فيه |
|---|---|
| `web-v1-backup/` | نسخة احتياطية من لعبة الموقع V1 (2026-11-03) |
| `platform-crazygames-v1/`, `platform-crazygames-v2/` | صفحتا CrazyGames لـ V1 وV2 |
| `dist/` | حزمتا ZIP لـ V1 وV2 |
| `assets-crazygames-v1-v2/` | أغلفة وفيديوهات ونص متجر V1/V2 |
| `tests-v2-a7/` | فحوصات A7 القديمة (مكتوبة لمعاينة V2) |
| `reports/` | تقارير V1/V2 |

الكود الكامل لكل نسخة موجود في فروعها: `backup/web-v1` و`backup/cg-stable-a7` و`feature/fair-precision`.
`tools/check-protected.sh` يتأكد أن ملفات هذا الأرشيف لم تتغير.
