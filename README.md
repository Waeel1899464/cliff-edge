## المجلدات

| المجلد | ما فيه |
|---|---|
| `index.html` | **كود اللعبة كله** (ملف واحد). كل النسخ تُبنى منه |
| `build.sh` | يبني صفحات V3. شغّله بدون كلمات ليعرض الخيارات |
| `platform/` | الصفحات المبنية: `crazygames-v3` و`web-v3` |
| `docs/` | ما ينشره الموقع (يُنشر من فرع `main` فقط) |
| `dist/` | الملف المرسل إلى CrazyGames |
| `assets/crazygames-v3/` | ملفات المتجر: النص، والأغلفة الثلاثة، والفيديوهات |
| `tests/` | الفحوصات |
| `tools/sim/` | المحاكي: يحسب صعوبة كل جرف قبل أن يلعبه أحد |
| `tools/check-protected.sh` | يتأكد أن الملفات المنشورة والمحفوظة لم تتغير |
| `marketing/` | حزمة الإطلاق: رسالة الأصدقاء، وأفكار مقاطع تيك توك، وقواعد النشر |
| `metrics/` | استعلامات أرقام اللاعبين، وتعديل قاعدة البيانات لـ V3 (طُبّق في 2026-11-05) |
| `reports/` | تقارير V3 (انظر `reports/README.md`) |
| `archive/` | كل ما يخص V1 وV2: الحزم، والأغلفة، والفيديوهات، والفحوصات، والتقارير القديمة |

## الأوامر

| ماذا تريد | الأمر | النتيجة اليوم |
|---|---|---|
| تشغيل كل الفحوصات | `sh tests/run-all.sh` | 178 فحصاً، كلها ناجحة (دقيقتان تقريباً) |
| بناء نسخة CrazyGames | `./build.sh crazygames-v3` | |

## نشر V3 على الموقع (تم في 2026-11-05 بموافقة صاحب المشروع)

1. طُبّق `metrics/v3-allow-events.sql` على قاعدة البيانات.
2. `./build.sh web`، ثم نُقل فرع `feature/worlds` إلى `main`.
3. للرجوع إلى V1 عند الحاجة: نضع `archive/web-v1-backup/docs-index.html` مكان `docs/index.html` على `main`.

## قواعد الحماية الدائمة

- لا نشر، ولا تعديل على `main` أو الموقع، دون موافقة صريحة من صاحب المشروع.
- لا حذف لأي بيانات لاعبين.
- لا إرسال شيء إلى CrazyGames من هنا. صاحب المشروع يرسل بنفسه.
- لا مفاتيح سرية في كود الصفحة. المفتاح الموجود مفتاح عام مخصص لصفحات الويب، والجدول يقبل الإضافة فقط.
