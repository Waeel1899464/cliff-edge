## CrazyGames rules followed
- Covers: 3 sizes, same scene and characters; the only text is the title (game font, Lilita One). No borders, icons or logos.
  Art: generated by the project owner (`src/owner-art-*.webp`); the square is cut from the landscape art.
- Videos: 15–20 s, under 50 MB, no sound, no black bars, no mouse cursor, no promotional text, no icons,
  no fast-forward (real time). Today's free bonuses were marked as used, so no reward buttons appear.
  The landscape video opens on the landscape cover for 0.5 s.

## Rebuild (from the repository root)
```
./build.sh crazygames-v3
node assets/crazygames-v5/src/capture_trailer_v5.js /tmp/trailer          # 6 scenes x 3 sizes, ~10 min
python3 assets/crazygames-v5/src/compose_trailer_v5.py /tmp/trailer assets/crazygames-v5
```
Covers: copy `src/owner-art-landscape.webp` → `land.webp`, `src/owner-art-portrait.webp` → `port.webp`,
`design/fonts/lilita-one-latin-400-normal.woff2` → `lilita.woff2` next to `src/make_covers_v5.js`, then `node make_covers_v5.js`.
